# Deployments

This folder contains deployment artifacts generated by the deploy script.

```
deployments/
├── localhost/          # Local Hardhat node deployments
│   └── deployment.json
├── sepolia/            # Sepolia testnet deployments
│   └── deployment.json
└── mainnet/            # Mainnet deployments (production)
    └── deployment.json
```

> **Note:** `deployment.json` files are git-tracked so that contract addresses
> are available to other packages (backend, frontend) without re-deploying.

## deployment.json shape

```json
{
  "network": "localhost",
  "chainId": "31337",
  "deployer": "0x...",
  "contracts": {
    "LandRegistry": "0x..."
  },
  "deployedAt": "2026-03-02T00:00:00.000Z"
}
```
